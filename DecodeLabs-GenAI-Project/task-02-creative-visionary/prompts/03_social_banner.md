# Prompt 3 — Social Media Banner

## Tool: DALL·E 3

### Prompt
```
Wide horizontal social media banner for a tech company "NexCore AI". 
Left side: abstract cyberpunk AI brain made of glowing cyan neural pathways 
on dark background. Right side: clean negative space (dark) for text overlay. 
Horizontal glowing line separator in neon violet. Overall palette: obsidian black, 
electric cyan, violet, chrome. Corporate-futuristic style. 
No text. 1200x628 pixel composition.
```

### Negative Prompt
```
--no text, letters, watermark, human faces, animals, warm colors, 
cluttered background, gradients, vintage style
```

### Settings
- **Aspect Ratio:** ~1.91:1 (LinkedIn / Facebook banner)
- **Midjourney:** `--ar 191:100 --v 6 --s 600`

### Usage Destinations
- LinkedIn Company Banner
- Facebook Cover Photo  
- Twitter/X Header
- YouTube Channel Art (crop to 2560×1440 center-safe zone)
