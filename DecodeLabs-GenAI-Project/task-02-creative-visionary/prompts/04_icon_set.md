# Prompt 4 — Icon Set (6 Icons)

## Tool: DALL·E 3 or Stable Diffusion

### Base Prompt Template (replace [ICON] for each one)
```
A single flat vector icon for a tech/AI app, cyberpunk-corporate aesthetic.
Icon: [ICON DESCRIPTION]. 
Style: Minimal line art with cyan glow on dark background. 
Electric cyan color (#00F5FF), dark obsidian background (#0A0A0F).
No gradients, clean geometric shapes, 512x512, app icon ready.
```

### 6 Icons to Generate

| # | Name | Replace [ICON] with |
|---|------|---------------------|
| 1 | Dashboard | "a grid of 4 glowing holographic squares representing a data dashboard" |
| 2 | AI Brain | "an abstract neural network brain made of geometric nodes and connecting lines" |
| 3 | Security Shield | "a hexagonal shield with a circuit pattern inside, cyberpunk style" |
| 4 | Data Upload | "an upward arrow emerging from a glowing data stream cylinder" |
| 5 | API/Integration | "two interlocking gears with a lightning bolt in the center" |
| 6 | Analytics | "a rising bar chart with a glowing trend line and data nodes" |

### Settings
- **Aspect Ratio:** 1:1 (512×512 each)
- **Midjourney:** `--ar 1:1 --v 6 --style raw --s 400`

### Consistency Tip
Generate the first icon, then use it as a style reference for all others:
`--sref [first_icon_URL] --sw 100`
