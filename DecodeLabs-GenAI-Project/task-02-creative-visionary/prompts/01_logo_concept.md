# Prompt 1 — Logo Concept

## Tool: DALL·E 3

### Prompt
```
A minimalist corporate logo for a tech company called "NexCore AI". 
The logo features an abstract geometric neural network node rendered as a 
crystalline hexagonal prism with glowing cyan circuit traces running through it. 
Dark obsidian background, electric cyan (#00F5FF) primary glow, neon violet 
secondary accent, chrome silver outlines. Flat vector style, no gradients, 
clean edges. Professional cyberpunk aesthetic. Centered composition on pure black.
```

### Negative Prompt (for Stable Diffusion / Midjourney)
```
--no text, letters, words, watermark, blurry, photorealistic, organic shapes, 
curves, flowers, animals, people, faces, low quality, pixelated
```

### Settings
- **Aspect Ratio:** 1:1 (1024×1024)
- **DALL·E 3 Style:** Vivid
- **Midjourney flags:** `--ar 1:1 --style raw --v 6`

### Design Intent
The hexagonal prism represents structure and precision. Cyan glow signals AI/tech. 
The neural trace pattern inside makes it immediately readable as an AI company.
